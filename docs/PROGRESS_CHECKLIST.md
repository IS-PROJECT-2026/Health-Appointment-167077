4. **Screenshot as you go** - Don't wait until the end

## 🆘 Common Issues & Solutions

### "Can't merge PR - branch protection"
**Solution:** Make sure you UNCHECKED "Require approvals" in branch protection settings

### "GitHub Pages shows 404"
**Solution:** Ensure `index.html` is in root folder (not in subfolder)

### "Firebase not loading"
**Solution:** Check Firebase SDK scripts are in HTML before your script.js

### "Lost track of what to do"
**Solution:** Check your Project Board - it shows exactly what's next
